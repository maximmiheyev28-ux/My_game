# Последний сигнал

Оригинальный 2D side-scroller для Android в жанре киберпанк-триллера.

## Версия 1.2.0 — Full Pixel-Art Rework

- Godot 4.7.2, Android ARM64, landscape, 60 FPS.
- Шесть детализированных панорамных уровней: неоновые мегаполисы, пагоды, традиционные кварталы, сакура, промышленные зоны, исследовательские комплексы и финальный реактор.
- Новые покадровые циклы героя: 8 idle, 10 run, 6 attack, 6 jump, 6 fall, 6 hurt, 6 parry и 6 stasis.
- Новые шестикадровые циклы четырёх классов врагов и шести боссов.
- Неоновый интерфейс, обновлённый портрет героя, более выразительные эффекты ударов, дождь, лепестки, свечение и отражения.
- Оригинальный synthwave-саундтрек, зацикленный в игровом уровне, поверх приглушённой городской атмосферы.
- «Стазис» остаётся компактным полем радиусом 78 px вокруг героя: он только останавливает ближайшие объекты и не наносит урон. После окончания эффекта их движение продолжается.

## Android-сборка

GitHub Actions восстанавливает основной Godot-проект, запускает исходный импорт ресурсов, затем применяет генератор графики/анимаций/музыки версии 1.2.0. После этого выполняется валидация проекта и headless-импорт Godot 4.7.2 с экспортом ARM64 APK.

[Открыть GitHub Actions](https://github.com/maximmiheyev28-ux/My_game/actions).

Текущий APK является debug-сборкой для установки и проверки. Для публикации в магазине нужен release-keystore. Реальный запуск и игровой процесс на физическом Android-устройстве необходимо проверить отдельно.
