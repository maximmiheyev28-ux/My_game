# Последний сигнал

**Последний сигнал** — оригинальный 2D side-scroller для Android в жанре киберпанк-триллера.

## Версия 1.1.0

- Godot 4.7.2, Android ARM64, landscape, 60 FPS.
- Шесть глав с разветвлённым сюжетом и отдельными боссами.
- Неоновый пиксель-арт: ночной мегаполис, пагоды, сакура, фонари, дождь, мокрые отражения и детализированные платформы.
- Расширенные циклы анимации героя, четырёх типов противников и шести боссов.
- Анимированные вступления глав и оригинальная зацикленная synthwave-музыка.
- Способность «Стазис»: компактное поле радиусом 78 px вокруг героя. Она временно останавливает объекты рядом с персонажем и не наносит урон; при окончании эффекта их движение возобновляется.
- Сенсорное управление с круглыми неоновыми кнопками и обновлённый HUD с портретом героя.

## Сборка Android

1. GitHub Actions восстанавливает исходный Godot-проект из файлов в папке .source.
2. Скрипт enhance_project.py генерирует графику, дополнительные кадры анимации и оригинальный саундтрек.
3. Godot 4.7.2 импортирует ресурсы и экспортирует APK для ARM64.
4. Сборка и проверка подписи доступны во вкладке Actions.

Последний APK публикуется как артефакт PosledniySignal-Android-ARM64-debug.

**Важно:** текущий APK — debug-сборка для установки и тестирования, а не release-пакет для публикации в Google Play. Проверка реальной игры на физическом Android-устройстве требуется отдельно.
