# Последний сигнал

Оригинальный 2D side-scroller для Android в жанре киберпанк-триллера.

## Версия 1.4.0 — Cinematic Pixel-Art Rework

- 52 новые hand-posed текстуры главного героя: 8 idle, 10 run и по 6 attack, jump, fall, hurt, parry, stasis. Ключевые позы отличаются положением ног, корпуса, рук, катаны и развевающегося плаща.
- Увеличенный читаемый силуэт героя, обновлённый портрет.
- Повторная художественная обработка шести панорам: фасады, балконы, вывески, провода, оконные блики, дождь, сакура и отражения.
- Шесть новых передних слоёв: крупные ветви сакуры, фонари, карнизы и провода, движущиеся относительно камеры.
- Шесть отдельных полноэкранных пиксельных задников для вступлений всех глав: медкомплекс, пустой город, лабораторный коридор, военный КПП, петля метро и центральное ядро.\n- Главное меню использует отдельную панорамную городскую сцену; катсцены получили лёгкое движение фона и короткую тряску камеры на ударе.\n- Видеоряд катсцен остаётся анимированным: движущиеся персонажи, частицы, дождь, неоновое мерцание, световой импульс и кинематографические шторки.\n- Оригинальный synthwave OST и городская атмосфера сохранены.
- «Стазис» — поле радиусом 78 px вокруг героя, без урона.

## Android-сборка

GitHub Actions восстанавливает Godot-проект, применяет v1.2 и v1.3 art passes, проверяет уникальность кадров и размеры спрайтов, затем импортирует сцены Godot 4.7.2 и экспортирует Android ARM64 APK.

[Открыть GitHub Actions](https://github.com/maximmiheyev28-ux/My_game/actions).

APK — debug-сборка для установки и проверки. Реальный игровой процесс на физическом Android-устройстве требуется проверить отдельно.
