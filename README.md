# Последний сигнал

Оригинальный 2D side-scroller для Android в жанре киберпанк-триллера.

## Версия 1.2.1 — Pixel-Art Rework + Parallax

- Godot 4.7.2, Android ARM64, landscape, 60 FPS.
- Шесть детализированных панорамных уровней: неоновые мегаполисы, пагоды, традиционные кварталы, сакура, промышленные зоны, исследовательские комплексы и финальный реактор.
- Отдельные передние слои с ветвями, фонарями и вывесками; они движутся относительно камеры и создают параллакс.
- Новые покадровые циклы героя: 8 idle, 10 run, 6 attack, 6 jump, 6 fall, 6 hurt, 6 parry и 6 stasis.
- Шестикадровые циклы четырёх классов врагов и шести боссов.
- Неоновый интерфейс, новый портрет героя, многослойные эффекты катаны, дождь, лепестки, свечение и отражения.
- Оригинальный synthwave-саундтрек в игровом уровне поверх приглушённой городской атмосферы.
- «Стазис» — компактное поле радиусом 78 px вокруг героя. Оно только останавливает ближайшие объекты и не наносит урон; после окончания эффекта их движение возобновляется.

## Android-сборка

GitHub Actions восстанавливает основной Godot-проект, применяет генератор графики/анимаций/музыки, добавляет параллакс-слои, проверяет ресурсы и экспортирует Android ARM64 APK в Godot 4.7.2.

[Открыть GitHub Actions](https://github.com/maximmiheyev28-ux/My_game/actions).

APK — debug-сборка для установки и проверки. Для Google Play нужен release-keystore. Игровой процесс на физическом Android-устройстве требуется проверить отдельно.
