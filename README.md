# ПОСЛЕДНИЙ СИГНАЛ — Android / Godot

**Версия исходников:** 1.0.0 — Pixel Art & Kinetic Stasis overhaul  
**Движок:** Godot 4.7.2  
**Платформа:** Android ARM64  
**Рендер:** 2D pixel art, viewport scaling, nearest-neighbour

## Что переработано в версии 1.0.0

- Новый оригинальный неон-нуар pixel-art набор: герой, четыре типа врагов, шесть боссов и шесть панорам.
- Кадровые анимации героя: idle, бег, прыжок, падение, атака, парирование, урон и стасис.
- Анимированные кадры врагов и боссов, пульсирующие платформы, дождь, лепестки, неоновые огни и отражения.
- Постановочные вступления шести актов с движением камеры, входом персонажей, ударом катаны, световым импульсом и диалогом с печатью текста.
- Способность «Стазис» замораживает пули, падающие капли и противников в локальном поле. Остановленные снаряды создают временные платформы; повторное нажатие выпускает энергию с десятикратным ускорением.
- Обновлены сенсорное управление, HUD, звуковые эффекты и пиксельные настройки рендера.

## Восстановление проекта

Исходники хранятся в `.source/part-001.b64` … `.source/part-052.b64`.

```bash
python3 restore_source.py
```

После восстановления откройте корень репозитория как проект Godot 4.7.2.

## Сборка APK

GitHub Actions workflow находится в `.github/workflows/android-build.yml`. Он восстанавливает исходники, устанавливает Godot 4.7.2, Java 17 и Android SDK, запускает проверку файлов, импорт и экспорт ARM64 debug APK.

[Открыть запуски GitHub Actions](https://github.com/maximmiheyev28-ux/My_game/actions).

**Важно:** APK, собранный этим workflow, является debug-сборкой для ручной установки. Перед публикацией в магазине нужны release-keystore и тестирование на физических Android-устройствах.
