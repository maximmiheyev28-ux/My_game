# Последний сигнал

Оригинальный 2D side-scroller для Android в жанре киберпанк-триллера.

## Текущая база: v1.3 visual rework; v1.4 cinematic integration in progress

- 52 hand-posed текстуры главного героя: 8 idle, 10 run и по 6 attack, jump, fall, hurt, parry, stasis.
- Шесть обработанных панорам и шесть отдельных передних параллакс-слоёв.
- Оригинальный synthwave OST и городская атмосфера.
- «Стазис» — локальное поле радиусом 78 px вокруг героя, без нанесения урона.
- v1.4 предусматривает шесть оригинальных кинематографических фонов и движение фона/камеры. Их исходный атлас пока не добавлен в репозиторий; CI явно помечает этот этап предупреждением и использует существующие фоны, пока материалы не будут готовы.

## Android-сборка

GitHub Actions восстанавливает Godot-проект, применяет v1.2 и v1.3 art passes, проверяет уникальность кадров и размеры спрайтов, затем импортирует сцены Godot 4.7.2 и экспортирует Android ARM64 debug APK. Если шесть исходных частей v1.4 cinematic atlas присутствуют, workflow интегрирует их и запускает проверку; если нет — не выдаёт отсутствие ассетов за успех интеграции и оставляет текущие фоны.

[Открыть GitHub Actions](https://github.com/maximmiheyev28-ux/My_game/actions).

APK — debug-сборка для установки и проверки. Успешная CI-сборка и проверка подписи не заменяют тестирование игрового процесса на физическом Android-устройстве.
