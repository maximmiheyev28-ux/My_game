# ПОСЛЕДНИЙ СИГНАЛ — Android / Godot

Репозиторий проекта игры «Последний сигнал» (версия 0.9.1 preview).

Исходный проект поставляется сжатым в `.source/` частях из-за ограничений загрузки бинарных файлов через подключение. После клонирования репозитория восстановите файлы командой:

```bash
python3 restore_source.py
```

После восстановления откройте каталог как проект Godot 4.7.2. Android APK собирается автоматически через GitHub Actions после добавления `build-request.txt` (этот файл уже будет добавлен после загрузки исходников). Готовый debug APK будет прикреплён к запуску workflow как artifact.

Это тестовая debug-сборка для установки вручную, не production-релиз.
